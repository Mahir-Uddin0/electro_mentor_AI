# ElectroMentor AI

ElectroMentor AI is a full-stack learning workspace for electrical students and
technicians. It combines grounded AI guidance, wiring-photo review, generated
safety checklists, practical-work assessments, reference PDFs, and task tracking
in one installable web application.

> AI output is educational support, not a substitute for site-specific risk
> assessment, applicable electrical codes, or supervision by a qualified
> professional. Always isolate and verify circuits before work.

## What it includes

- **Grounded AI mentor** — conversational electrical guidance with citations
  retrieved from an indexed PDF knowledge base.
- **Photo fault analysis** — structured review of JPG, PNG, WebP, HEIC, and HEIF
  wiring photos, including severity, confidence, PPE, tools, and repair steps.
- **Safety checklists** — a browsable PDF library plus task-specific checklists
  generated by Gemini.
- **Practical assessments** — upload an MP4, MOV, or WebM work video, answer ten
  generated questions, and receive competency scores and suggestions.
- **Guide library** — authenticated, searchable access to wiring and circuit PDF
  resources without exposing server file paths.
- **Practice tracker** — user-owned tasks with priority, due dates, and enforced
  status progression.
- **English and Bangla** — localized interface text and language-aware AI
  responses.
- **Installable PWA** — a production service worker provides a minimal offline
  shell while keeping credentials and user data out of the cache.
- **Built-in observability** — Prometheus metrics, Loki logs, Alloy collection,
  and a provisioned Grafana dashboard.

## Architecture and technology

| Area | Technology | Responsibility |
| --- | --- | --- |
| Web | Next.js 16, React 19, TypeScript, Tailwind CSS 4 | UI, PWA, session client, and typed API calls |
| API | FastAPI, Pydantic, SQLAlchemy | Authentication, user data, PDF delivery, and AI workflows |
| AI/RAG | Gemini API, Chroma, PyMuPDF4LLM | Generation, multimodal analysis, embeddings, and retrieval |
| Storage | SQLite, local private files, Chroma | Accounts, sessions, tasks, conversations, assessments, videos, and vectors |
| Operations | Docker Compose, Prometheus, Loki, Alloy, Grafana | Deployment, health checks, metrics, logs, and dashboards |

The browser talks to FastAPI directly during local development. In Docker, it
uses `/backend-api`; Next.js proxies that path to `backend:8000` on the private
Compose network.

## Quick start with Docker Compose

### Requirements

- Docker Engine with Docker Compose v2
- A Gemini API key for each user who will use AI features

For a first-time installation:

```bash
cp .env.example .env
openssl rand -hex 32       # use for AUTH_JWT_SECRET
openssl rand -hex 32       # use a different value for API_KEY_ENCRYPTION_SECRET
openssl rand -base64 32    # use for GRAFANA_ADMIN_PASSWORD
```

Add the generated values to `.env`, then start the complete application and
monitoring stack:

```bash
docker compose config --quiet
docker compose up --build -d
docker compose ps
```

| Service | URL |
| --- | --- |
| Application | <http://localhost:3000> |
| FastAPI | <http://localhost:8000> |
| API documentation | <http://localhost:8000/docs> |
| Health check | <http://localhost:8000/api/v1/health> |
| Metrics | <http://localhost:8000/metrics> |
| Grafana | <http://localhost:3001> |

Create an account, open **Settings**, and save your Gemini API key. The key is
encrypted before it is stored and is never returned by the API. AI features
require this per-user key; authentication, tasks, and PDF browsing do not.

Use `docker compose logs -f backend frontend` to follow application logs. Normal
container recreation preserves all named volumes. Do not run
`docker compose down --volumes` unless you intend to delete application and
monitoring data.

## Local development

### Requirements

- Python 3.11 or newer
- [uv](https://docs.astral.sh/uv/)
- Node.js 22 or newer
- npm

### 1. Start the backend

```bash
cd backend
cp .env.example .env
openssl rand -hex 32
openssl rand -hex 32
```

Put the two different generated values in `AUTH_JWT_SECRET` and
`API_KEY_ENCRYPTION_SECRET` in `backend/.env`, then run:

```bash
uv sync --extra dev
uv run uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

FastAPI creates `backend/data/electromentor.db` and the required tables and
triggers on startup. No separate migration command is needed.

### 2. Start the frontend

In another terminal:

```bash
cd frontend
cp .env.example .env.local
npm ci
npm run dev
```

Open <http://localhost:3000>. The default frontend configuration enables the
general preview API, but authentication and the implemented feature APIs still
use FastAPI. Set `NEXT_PUBLIC_USE_MOCK_API=false` for a fully backend-driven
session. See [frontend/README.md](frontend/README.md) for every feature switch
and route.

## Gemini and the RAG knowledge base

Runtime AI operations use the Gemini key saved by the signed-in user. The
optional `GEMINI_API_KEY` in `backend/.env` is used only by the offline document
ingestion command.

To build the assistant's retrieval index:

```bash
cd backend
# Set GEMINI_API_KEY in backend/.env first.
# Place source PDFs in data/raw_pdfs/.
uv run python -m rag.ingestion.pipeline
```

The pipeline converts each PDF to Markdown, creates semantic chunks, embeds the
chunks, and writes a persistent Chroma collection:

```text
backend/data/raw_pdfs/  -> source PDFs
backend/data/markdown/  -> extracted Markdown
backend/data/chunks/    -> JSONL chunks
backend/data/chroma/    -> vector index
```

Unchanged documents are skipped using their SHA-256 hash and pipeline
configuration fingerprint. Force a rebuild with:

```bash
uv run python -m rag.ingestion.pipeline --force
```

The default ingestion limits are intentionally conservative. Adjust the
`GEMINI_EMBEDDING_*` variables only after checking the quota for your Gemini
project.

PDFs placed in `backend/data/safety_checklist/` and
`backend/data/wiring_circuit_guide_library/` are discovered dynamically by the
corresponding libraries; adding a file does not require a database migration.

## API overview

All application routes use the `/api/v1` prefix. Except for health,
registration, login, refresh, and logout, send the access token as
`Authorization: Bearer <token>`.

| Route group | Purpose |
| --- | --- |
| `/auth` | Register, sign in, rotate refresh tokens, sign out, and get the current user |
| `/settings/gemini-api-key` | Check, save, or delete the current user's encrypted Gemini key |
| `/conversations` | Create, list, rename, delete, and message persistent conversations |
| `/photo-analysis` | Analyze a wiring photo |
| `/safety-checklists` | Browse PDFs and generate a task-aware checklist |
| `/guides` | Browse, view, and download reference PDFs |
| `/tasks` | Manage the current user's practice tasks |
| `/practical-assessments` | Create, complete, evaluate, and review video assessments |

The OpenAPI explorer at `/docs` is the authoritative request and response
reference when `DOCS_ENABLED=true`.

## Configuration

Use the committed examples as the source of truth:

- [`.env.example`](.env.example) — Docker Compose secrets, Grafana, and optional
  image names.
- [`backend/.env.example`](backend/.env.example) — backend, Gemini, storage,
  upload, retrieval, and ingestion settings.
- [`frontend/.env.example`](frontend/.env.example) — backend URL and mock-mode
  switches.

Never commit populated `.env` files. Keep `API_KEY_ENCRYPTION_SECRET` stable:
changing it makes existing saved Gemini keys unreadable. Generate it separately
from `AUTH_JWT_SECRET`.

## Production deployment

`prod.docker-compose.yml` pulls the versioned application images from the
company registry and starts the same private monitoring topology:

```bash
docker login registry.acimisai.com
cp .env.example .env      # first deployment only
# Configure all required secrets in .env.
docker compose -f prod.docker-compose.yml config --quiet
docker compose -f prod.docker-compose.yml pull
docker compose -f prod.docker-compose.yml up -d
```

The production file currently deploys:

- `registry.acimisai.com/electro_mentor_ai-frontend:v1.0.0`
- `registry.acimisai.com/electro_mentor_ai-backend:v1.0.0`

Clone the complete repository on the host because Compose mounts the monitoring
configuration and provisioned Grafana dashboard from `monitoring/`.
